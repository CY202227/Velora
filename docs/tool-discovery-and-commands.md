# 插件与长命令工具

MCP 工具以 `mcp__`、清理后的服务/工具名称和原始身份的 SHA256 短摘要组成稳定名称，最长 62 字符。不同服务的同名工具及清理后相同的名称不会覆盖内置工具。原始工具名仍用于向 MCP 服务发起调用。

已有角色卡中的插件工具白名单需要更新为新名称；旧裸名称不会自动授权新插件。内置工具名称保持不变。

插件参数定义默认不加入初始模型请求。`tool_search` 仅搜索角色白名单允许的插件，按名称/描述关键词命中数量排序并稳定排序，最多返回 10 项；不是语义检索或 BM25。搜索返回定义并在当前轮开放调用，下一次模型请求包含新定义。其他会话不继承发现结果。未命中时可换用插件描述中的关键词。`tool_search` 为保留名称。

`command_session` 支持 `start`、`poll`、`cancel`。启动参数为 `command`，后续以 `execution_id` 查询，`wait_ms` 范围 1–10000。每轮最多同时运行四个命令；查询返回每个输出流最近 16000 字符的窗口，完整终态仍走持久执行和输出存储。它不支持 stdin 输入或交互终端。

命令使用原有执行权限、隔离、超时、回执、文件检查点及输出预算。需要交互审批的命令继续使用 `run_shell`，长命令入口不接受额外授权。句柄只属于当前轮，其他会话无法查询或取消。正常收尾必须先处理运行中的句柄；取消、异常或步数耗尽时清理剩余命令。取消不代表副作用回滚。

包含长命令会话的运行暂不支持跨重启恢复，恢复入口明确拒绝，必须查看持久执行证据，不得自动重放。插件搜索可重新执行，但不会在新一轮继承之前开放的工具集合。
